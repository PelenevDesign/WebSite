# Админка сайта

Админ-панель работает на PHP + MySQL и не требует Node.js, сборки или повторного деплоя после установки.

## Первичная установка на Beget

1. Загрузите файлы сайта в корневую папку домена, сохранив структуру каталогов (включая `uploads/.htaccess` — он запрещает исполнение кода в папке загрузок).
2. В панели Beget создайте базу MySQL и пользователя базы.
3. Заполните данные базы и пароль администратора в `config.php`.
4. Откройте `https://ваш-домен.ru/install.php`, введите пароль администратора и нажмите «Установить».
5. **Удалите `install.php` с хостинга.**

После этого открывайте `/admin`. Все изменения текстов и картинок сохраняются в MySQL и моментально выводятся на сайте. Загруженные изображения попадают в `/uploads`.

В разделе «Кейсы» можно создавать проекты без изменения кода: задавать несколько категорий, загружать обложку и галерею, менять порядок перетаскиванием, редактировать и удалять проекты. Каждый проект получает страницу `case.php?id=...` с адаптивной галереей и полноэкранным просмотром.

Для переноса сайта скопируйте файлы, экспортируйте и импортируйте базу MySQL, затем измените доступы в `config.php`.

## Разделы админки (v2)

- **Дашборд** — новые заявки, счётчики за сегодня/неделю/месяц, последние кейсы и журнал действий.
- **Заявки** — все обращения с формы: поиск, фильтр по статусу, смена статуса (Новая / В работе / Завершена). Каждая новая заявка дублируется письмом на адрес из `config.php → lead_email`; при сбое почты запись в базе всё равно остаётся.
- **Кейсы** — создание/редактирование/удаление, статус (Опубликован / Черновик / Скрыт), несколько категорий, обложка, галерея без ограничений, порядок фото и кейсов перетаскиванием. Черновики и скрытые не видны на сайте и отдают 404 по прямой ссылке.
- **Медиатека** — все файлы из `/uploads`: поиск, загрузка пачкой, копирование URL, удаление (занятые на сайте файлы защищены).
- **Контент** — тексты, заголовки, кнопки, изображения, ссылки соцсетей, пути к видео, футер.
- **SEO** — title и description главной и страницы кейсов.
- **Интеграции** — Яндекс Метрика / GA / GTM: код вставляется целиком и автоматически подключается на всех страницах.

## Пароль администратора

В `config.php` два поля. Если заполнен `admin_password_hash`, поле `admin_password` игнорируется — это рекомендуемый режим: пароль нельзя прочитать, даже получив доступ к файлам.

Получить хэш можно двумя способами:
- на странице `install.php` — блок «Получить хэш пароля» (нужен текущий пароль);
- в консоли: `php -r "echo password_hash('ваш-пароль', PASSWORD_DEFAULT);"`.

Готовую строку вставьте в `admin_password_hash`, а `admin_password` очистите (`''`).

Вход защищён от перебора: после 5 неудачных попыток IP блокируется на 15 минут. Счётчик хранится в файле `.htlogin-attempts.json` в корне (Apache такие файлы наружу не отдаёт); чтобы снять блокировку вручную, удалите этот файл.

## Безопасность — чек-лист перед запуском

- [ ] `install.php` удалён с хостинга.
- [ ] `admin_password_hash` заполнен, `admin_password` пуст.
- [ ] Пароль длинный и несловарный.
- [ ] `uploads/.htaccess` залит на сервер.
- [ ] В корне домена нет архивов и резервных копий (`*.zip`, `*.bak`, `*.sql`) — они доступны по прямой ссылке.
- [ ] Сайт открывается по HTTPS (иначе сессионная кука админки идёт без флага `secure`).
