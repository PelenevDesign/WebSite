1. **Работаем строго по фазам ниже. После каждой фазы — СТОП.** Показываешь результат, ждёшь моего «ок / go / дальше». Без апрува следующую фазу не начинаешь.

5. Стек фиксированный: vanilla + GSAP + ScrollTrigger + Lenis через CDN. Не тащи React/Next/Tailwind/сборщики.
6. Токен-эффективность: не дублируй CSS, используй переменные из `:root`, не переписывай уже одобренные файлы целиком без нужды — правь точечно.

## ФАЗА 2 — Hero
Лейаут (Image 1): топбар; слева подзаголовок (3 строки) + пилюля «Book a call»; справа выключенный столбец услуг (Brand strategy & positioning → Motion Design, выключка вправо); внизу гигант «Cello Studio.» на всю ширину; фон — видео/фото портрета (тёмное, ч/б). Плейсхолдер видео `assets/video/hero.mp4` + постер.

**Анимации (покадрово):**
- **Load-in (таймлайн, старт сразу):**
  1. Фон: `scale 1.12 → 1` за `1.6s power2.out` + `opacity 0→1` за `0.8s`.
  2. Подзаголовок: построчный подъём из-под маски `y:110%→0`, стаггер `0.08s`, `power3.out`, старт `+0.2s`.
  3. Список услуг справа: fade+`y:20→0`, стаггер `0.06s`, старт `+0.4s`.
  4. Кнопка «Book a call»: `y:20→0 opacity 0→1`, старт `+0.5s`.
  5. Гигант «Cello Studio.»: подъём из-под маски `y:100%→0` за `1.1s power4.out`, старт `+0.35s`. Точка «.» вермилион появляется с лёгким `scale 0→1` на `+0.1s` позже слова.
- **Sticky-гигант при скролле:** контейнер гиганта `position: sticky; bottom: 0`. Пока скроллим герой — надпись стоит внизу; следующая (белая) секция наезжает сверху и «выталкивает»/перекрывает её. Реализация: ScrollTrigger pin блока гиганта на высоту героя, лёгкий `y`-parallax (`yPercent: 0 → -15`) при уходе. Скраб `scrub: true`.
- **Фон-parallax:** при скролле фон `yPercent 0 → 12`, `scrub`.

**Риск назвать:** на iOS `100vh` прыгает → `100svh`; видео на мобиле заменить фото.

**СТОП.** Показать load-in и поведение гиганта при скролле.

## ФАЗА 3 — Projects (SIGNATURE: sticky-стек карточек) ⚠️ ключевая фаза
Это тот самый эффект «наезжающих карточек», ради которого делаем клон. Отнесись максимально аккуратно.

Перед проектами — **Intro-заголовок** (Image 2): крупный параграф «We design brands and visual systems…» с инлайн-иконками вермилион между слов; слева список 01–05; справа большая картинка. Reveal: параграф — по-словный подъём из-под маски со стаггером `0.02s`; список — fade+`y` стаггер `0.08s`; картинка — `scale 1.1→1` + `clip-path` раскрытие снизу вверх, `scrub` на входе.

**Стек проектов — механика (покадрово):**
- 5 секций-карточек подряд. Каждая карточка: `position: sticky; top: 0; height: 100svh`. За счёт того что все sticky с одинаковым `top`, при скролле следующая наезжает поверх предыдущей.
- Каждая карточка = «обложка проекта»: сначала (Image 3) полноэкранное фото + слева снизу гигантское название проекта + справа таблица метаданных (Industry/Company/Timeline/Services) с пунктирными разделителями; при доскролле карточка «раскрывается» в состояние (Image 4): фото уезжает в левую колонку-квадрат с radius, справа появляется название + подпись + чёрная кнопка «View Project», снизу номер `01…05` + пунктир + статус.
- **Наезд:** уходящая (нижняя) карточка при перекрытии получает `scale: 0.94` и затемнение `brightness(.7)` — скрабом по прогрессу перекрытия. Приходящая въезжает от `y:100%`→`0` (за счёт нормального потока + sticky) с `border-radius` сверху `24px`.
- Внутренний контент каждой карточки анимируется по её собственному ScrollTrigger: название `y:110%→0` из-под маски; метаданные — построчный fade со стаггером `0.06s`; переход «фото фуллскрин → фото в квадрат» — `clip-path`/`width` скраб `scrub: true`.
- Порядок номеров и статусы: 01 Lunet Atelier / Completed, 02 Factory Clayhouse / Completed, 03 Aural Audio / Ongoing, 04 Leafico Botanics / Completed, 05 Bloom Bureau / Completed.

**Риск назвать:** sticky внутри Lenis может дёргаться; `will-change: transform` на карточках; на мобиле стек упростить в вертикальную ленту (карточки друг под другом без наезда) — согласуем в фазе адаптива.

**СТОП. Это критичная фаза — показать плавность наезда и раскрытие карточки, жду отдельного апрува.**
