# Personal Cloud для Beget

Приложение находится в `/cloud/`, а короткая ссылка для входа — `/file`.

1. Импортируйте `schema.sql` в ту же MySQL-базу, что использует сайт.
2. Проверьте доступы в `cloud/config.php`.
3. Создайте каталог `cloud-storage` рядом с `public_html` и выдайте PHP право записи.
4. Откройте `/cloud/login.php`. Первоначальный пароль: `Koshak`.
5. Работайте только через HTTPS. Лимит хранилища по умолчанию — 8 GB и отображается в панели.

Файлы не лежат в public web root: скачивание идёт через авторизованный `api.php`. Загрузка чанками по 10 MB не требует отправлять весь большой файл одним POST. Сервис не сжимает и не изменяет оригиналы.

Для production рекомендуется вынести `config.php` за пределы web root и заменить пароль на собственный hash `password_hash()`.
