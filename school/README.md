# Онлайн-школа: кабинет ученика + админка

- Кабинет ученика: `/school/`
- Админка автора: `/school/admin/` — стартовый пароль задаётся в `config.php` на сервере:
  `'school_admin_password' => '...'`. После первого входа он хранится хэшем в базе,
  строку из config.php можно удалить; дальше пароль меняется в «Настройках».

Установка не нужна: таблицы `school_*` создаются в той же MySQL-базе сайта при первом открытии.
Видео хранятся вне `public_html` (`school-storage/` рядом с ней); если хостинг не даёт туда писать —
в `school/_storage/`, закрытой от прямого доступа.

## Как работать
1. «Курсы» → «Новый курс» → «Уроки» → «Новый урок»: название, описание, материалы, видео.
2. Видео: файл MP4 (H.264) любого размера — грузится частями по 4 МБ; или ID/ссылка Kinescope.
3. «Ученики» → «Добавить»: имя, почта, курсы, срок доступа. Пароль создаётся автоматически,
   показывается один раз — кнопка «Скопировать» даёт готовое сообщение для ученика.

## Защита
- Вход по личной почте и паролю, один аккаунт = одно устройство (новый вход выбивает старый).
- Видео отдаёт `stream.php` только плееру кабинета: подписанный токен + активная сессия
  + `Sec-Fetch-Dest: video`, не больше 2 МБ за запрос. Прямая ссылка в новой вкладке не открывается.
- Персональный водяной знак (почта, имя, ID) поверх видео и в полноэкранном режиме;
  удаление знака через DevTools останавливает плеер.
- Пауза и чёрный экран при потере фокуса (ножницы Windows, переключение окна),
  PrintScreen и Cmd+Shift+3/4/5 на Mac; запрет контекстного меню, выделения, печати, Ctrl+S.
- Журнал: входы, IP, открытые уроки, попытки скриншотов, подозрение на передачу аккаунта.

Ограничение: браузер не позволяет полностью запретить запись экрана или съёмку на телефон.
Блокировку записи экрана даёт только DRM — для этого есть вариант Kinescope
(в Kinescope включить DRM и ограничение по домену). Водяной знак сдерживает утечки:
по нему видно, кто слил видео.
