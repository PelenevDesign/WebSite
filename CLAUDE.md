# CLAUDE.md — Cello Studio (клон главной страницы)

> Референс: https://cello.framer.website
> Задача: пиксель-в-пиксель клон **только главной страницы** на чистом HTML/CSS/JS + GSAP + Lenis.
> Контент (тексты, фото, видео) — плейсхолдеры, заказчик заменит сам. Приоритет — **композиция и анимация 1в1**.

---

## 0. Правила работы (обязательно к соблюдению)

- Стек: **vanilla HTML + CSS + JS**, без сборщиков и фреймворков. GSAP + ScrollTrigger + Lenis через CDN.
- Не добавляй ничего, о чём не просили. Без «улучшений» дизайна, без лишних секций.
- Один HTML-файл `index.html`, один `styles.css`, один `main.js`. Ассеты — в `/assets`.
- Каждую секцию собираем **по фазам** с остановкой на апрув (см. PROMPT.md). Не беги вперёд.
- Технические риски проговаривай сразу (перф видео, sticky-стек на мобиле, `100vh` на iOS).
- Комментарии в коде — минимально, только там где неочевидно. Без объяснений в чате без запроса.
- Мобильную адаптацию делаем в конце отдельной фазой, не смешиваем с десктопом.

## 1. Арт-дирекшн

Швейцарский минимализм / editorial. Много воздуха, крупная гротескная типографика, контраст чёрных «кинематографичных» секций и белых «галерейных». Единственный цветовой акцент — вермилион (красно-оранжевый). Скругления мягкие, крупные. Анимации плавные, «дорогие», без резкости.

Ритм страницы: **тёмный герой → белые проекты (sticky-стек) → тёмный/белый About → белые Services → Process → тёмный Pricing → FAQ → Blog → тёмный футер-CTA**. Чередование тёмных и светлых блоков — часть айдентики.

## 2. Цвета (токены)

```css
:root{
  --ink:        #0A0A0A;   /* почти чёрный — текст на светлом, фон тёмных секций */
  --paper:      #FFFFFF;   /* белый фон светлых секций */
  --paper-soft: #F4F4F4;   /* серые карточки статов, инпуты */
  --paper-line: #EAEAEA;   /* пунктирные разделители, границы */
  --muted:      #8A8A8A;   /* вторичный текст, подписи, номера 02/03 */
  --muted-dark: #A6A6A6;   /* вторичный текст на тёмном фоне */
  --accent:     #F5320E;   /* вермилион — точка в лого, номера 01, иконки, тумблер */
  --on-dark:    #FFFFFF;   /* текст на тёмном */
  --on-dark-2:  rgba(255,255,255,.55); /* вторичный на тёмном */
}
```

Правила акцента: вермилион — только точка «.» в «Cello Studio.», активный номер `01`, инлайн-иконки в заголовке About, кружок тумблера Pricing, кнопки-плюсы `⊕`, линия-график на тёмных секциях. Больше нигде. Красным никогда не заливаем крупные плоскости.

## 3. Типографика

Дисплейный и текстовый — **один гротеск с геометрией и чуть закруглёнными терминалами** (близко к Framer-дефолту). Ставим переменный гротеск, максимально похожий на оригинал:

- **Display / Body:** `"Inter Tight"` (Google Fonts, вариативный) — основной. Фолбэк: `"Inter", system-ui, sans-serif`.
  - Оригинал использует шрифт с мягкими терминалами; если нужно ближе — альтернатива `"General Sans"` или `"Switzer"` (Fontshare). Держим один вариант, не миксуем.
- **Utility / caption / номера:** тот же гарнитур, вес 500, tracking чуть плотнее.

Отсутствие засечек обязательно. Не подключай serif.

### Тип-шкала (desktop)

| Роль | clamp | Вес | Line-height | Letter-spacing |
|---|---|---|---|---|
| Гигант-лого «Cello Studio.» | `clamp(4rem, 15vw, 15rem)` | 600 | .9 | -0.03em |
| H2 секций «Pricing/Services/FAQ» | `clamp(3rem, 8vw, 8rem)` | 600 | .95 | -0.02em |
| H2 About-параграф (крупный) | `clamp(1.6rem, 3.4vw, 3.2rem)` | 500 | 1.15 | -0.01em |
| H3 карточек проектов | `clamp(1.4rem, 2.2vw, 2rem)` | 600 | 1.1 | -0.01em |
| Hero-подзаголовок | `clamp(1.3rem, 2vw, 1.9rem)` | 500 | 1.2 | -0.01em |
| Body | `1rem–1.125rem` | 400 | 1.5 | 0 |
| Caption / label / номер | `.8rem–.9rem` | 500 | 1.3 | 0 |

Заголовки — sentence case как в оригинале, не uppercase (кроме бегущей строки футера «WE ARE CELLO»).

## 8. Анимации — общие принципы (детали в PROMPT.md)

- **Плавный скролл:** Lenis (`lerp ~0.1`), синхронизирован с `ScrollTrigger.update`.
- **Easing по умолчанию:** `power3.out` для входов, `power2.inOut` для скролл-скраба. Длительности 0.6–1.2s.
- **Reveal-паттерн:** заголовки — построчный/по-словный подъём с `y: 110%` из-под маски (`overflow:hidden` на строке). Картинки — `scale 1.08→1` + `clip-path` раскрытие или fade+`y`.
- **Sticky-стек проектов** — сигнатурный эффект (см. PROMPT.md, фаза 3). Каждая карточка `position: sticky; top: 0`, следующая наезжает; уходящая слегка `scale(.94)` + затемнение.
- **Гигант «Cello Studio.»** прилипает снизу героя и «выталкивается» следующей секцией (sticky + parallax).
- **Счётчики** статов — от 0 до значения по входу во вьюпорт (`0→10`, `0→12`, `0→6`, `0→40`, суффиксы `+` сохраняем).
- **Live-время** Local/Your — реальный `Intl.DateTimeFormat`, обновление раз в 1s.
- **Marquee** футера — бесконечная лента на GSAP, реверс направления по скроллу опционально.
- **Reduced motion:** при `prefers-reduced-motion: reduce` отключаем скраб/параллакс, оставляем мгновенные состояния.

## 9. Технические ноты / риски

- `100vh` на iOS «прыгает» — использовать `100svh`/`100dvh`.
- Sticky-стек тяжело ведёт себя внутри Lenis — тестировать скролл-скорость, при просадке fps перевести затемнение уходящих карточек на `will-change: transform, opacity`.
- Видео-фон: `muted playsinline autoplay loop preload="metadata"`, постер-заглушка для первой отрисовки, на мобиле — статичное фото вместо видео.
- Шрифты грузим с `display=swap`, критичный вес — предзагрузка.
- Все интерактивные элементы — видимый `:focus-visible`.
