# Модуль «Услуги» — реализован

Раздел «Услуги» в админке готов: список, создание, редактирование, удаление.
Контент страниц `/services/<slug>/` берётся из таблицы `cms_services`, а пока
она пуста — из `services/_data.php` (откат, чтобы сайт не лёг до наполнения).
При первом заходе в раздел услуги переносятся из файла в базу автоматически.

## Что осталось проверить на боевом хостинге

PHP локально не исполняется, поэтому серверная часть проверена только статически:

- откройте админку → «Услуги»: должно появиться 5 услуг, перенесённых из файла
- отредактируйте одну, сохраните, откройте её страницу — текст должен смениться
- проверьте калькулятор: варианты, опции, «входит бесплатно», пересчёт суммы
- удалите тестовую услугу — страница должна отдавать 404
- убедитесь, что кейсы и гайды не сломались

## Известные ограничения

- Порядок услуг меняется только через `sort_order` в БД: перетаскивания в
  списке пока нет (эндпоинт `services-reorder` готов, UI — нет)
- `services/<slug>/index.php` остаются файлами-заглушками: новая услуга из
  админки требует создать такой каталог вручную ИЛИ добавить правило в
  `.htaccess`:

      RewriteRule ^services/([a-z0-9-]+)/?$ /services/_router.php?slug=$1 [L,QSA]

  и файл `_router.php` с содержимым `<?php $slug = $_GET['slug'] ?? ''; require __DIR__ . '/_template.php';`
